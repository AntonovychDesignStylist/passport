# Паспорт интерьера — веб-анкета Antonovych Design

Заказчик открывает ссылку на телефоне и видит ту же анкету, что в PDF, страница в страницу.
Галочки ставятся нажатием на квадратик, подпись или фото. Ответы печатаются нажатием на линию.
Фото открывается на весь экран по лупе в его углу. Страницу можно увеличить двумя пальцами.
Черновик сохраняется на телефоне сам. При отправке собирается PDF с ответами и уходит на
указанную почту. Ответы нигде больше не хранятся.

Ссылка: `https://<аккаунт>.github.io/passport/standard/`.
Метка объекта: `…/standard/?p=vivaldi-12`. Код попадёт в PDF и в тему письма.
В код нельзя писать имена и телефоны, только название объекта.

## Из чего состоит

| Файл | Что это |
|---|---|
| `standard/index.html` | страница анкеты (одинаковая для всех типов паспорта) |
| `content/standard/questions.json` | **всё содержание анкеты**: тексты вопросов и вариантов, координаты квадратиков, линий и фото на страницах |
| `content/standard/images-map.md` | таблица «вопрос → вариант → файл фото» |
| `assets/img/standard/pages/` | страницы анкеты картинками (фон) |
| `assets/img/standard/` | фото вариантов для просмотра в полный экран |
| `assets/js/app.js`, `assets/js/pdf.js` | движок анкеты и сборка PDF (общие для всех типов) |
| `assets/fonts/` | урезанные шрифты Gilroy и Cormorant |
| `config.js` | адрес скрипта отправки и почта по умолчанию |
| `apps-script/Code.gs` | скрипт Google для отправки писем |

## Как поменять текст вопроса или варианта

1. Откройте `content/standard/questions.json` на GitHub и нажмите карандаш (Edit).
2. Найдите текст поиском (Ctrl+F) и поправьте его в кавычках после `"label":`.
3. Нажмите **Commit changes**. Сайт обновится сам за 1–2 минуты.

Эти тексты попадают в сводку ответов и в PDF. На самих страницах анкеты текст «нарисован»,
как в исходном PDF. Чтобы поменять вид страницы, нужен новый исходный PDF. Такие страницы
пересобираются скриптами из папки `source/scripts/`, она хранится только у студии.

## Как добавить новый тип паспорта (классика, офисы, коммерция)

1. Сверстайте новую анкету в PDF в том же стиле и передайте её исполнителю.
2. Исполнитель запускает скрипты из `source/scripts/` для нового PDF. Получаются:
   `content/<тип>/questions.json`, `content/<тип>/images-map.md`, папка `assets/img/<тип>/`.
3. На GitHub скопируйте папку `standard` в папку с новым именем, например `classic`.
   Внутри только `index.html`, менять в нём ничего не нужно: тип берётся из имени папки.
4. Загрузите файлы из шага 2. Новая ссылка: `https://<аккаунт>.github.io/passport/classic/`.

Движок, дизайн и отправка писем у всех типов общие, отдельно ничего настраивать не надо.

## Как подключить свой адрес (passport.antonovych-design.kz)

1. У регистратора домена добавьте DNS-запись: тип **CNAME**, имя **passport**,
   значение **`<аккаунт>.github.io`**.
2. На GitHub: репозиторий → **Settings → Pages → Custom domain**. Впишите
   `passport.antonovych-design.kz`, нажмите **Save**, затем включите **Enforce HTTPS**
   (появится через 10–60 минут).
3. Новая ссылка: `https://passport.antonovych-design.kz/standard/`.

## Почта и лимиты Google

Письма отправляет Google Apps Script от имени аккаунта, в котором он развёрнут.
Лимиты Google на отправку писем в сутки:

- обычный аккаунт Gmail: 100 получателей в сутки;
- Google Workspace (рабочая почта на своём домене): 1 500 получателей в сутки.

Каждый адрес в поле «Кому» считается отдельным получателем. Рекомендуем разворачивать скрипт
от рабочего аккаунта студии. В скрипте есть свой лимит: 60 писем в сутки и 3 отправки
с одной анкеты. Их можно поменять в свойствах скрипта, см. `DEPLOY.md`.

## Что где хранится

- Ответы — только в черновике на телефоне заказчика (localStorage) и в отправленном письме.
- Google-таблиц и файлов на Диске скрипт не создаёт. Копия письма остаётся в «Отправленных»
  аккаунта, от которого работает скрипт.
- Аналитики и трекеров нет. Страница закрыта от поисковиков (`noindex`).
