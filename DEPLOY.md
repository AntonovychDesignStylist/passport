# Публикация: пошагово

Два этапа. Первый — сайт на GitHub Pages, после него анкету уже можно заполнять и скачивать
PDF. Второй — отправка писем через Google, после него PDF уходит на почту.

Пароли, вход в аккаунты и подтверждения по почте делает сотрудник студии сам.

---

## Этап 1. Сайт на GitHub Pages

### 1.1. Аккаунт GitHub
Аккаунт студии регистрируется на `ap@antonovych-design.kz` (https://github.com/signup).
Имя аккаунта будет в ссылке: `https://<имя>.github.io/passport/`.

### 1.2. Репозиторий
1. Справа вверху **+** → **New repository**.
2. Repository name: `passport`.
3. Отметьте **Public**. Бесплатные Pages работают только с публичными репозиториями,
   поэтому в репозитории лежит только готовый сайт, без исходного PDF.
4. Галочки README / .gitignore / license **не ставить**. Нажмите **Create repository**.

### 1.3. Загрузка файлов
Файлы загружает исполнитель командой `git push`. При первой загрузке откроется окно
входа в GitHub, войдите в аккаунт студии.

Если загружать вручную: на странице репозитория **uploading an existing file**, затем
перетащите содержимое папки проекта. Папку `source` и файлы `TZ_*.md`, `CLAUDE.md`,
`*.pdf` **не загружать**.

### 1.4. Включить Pages
1. Репозиторий → **Settings** → слева **Pages**.
2. Source: **Deploy from a branch**. Branch: **main**, папка **/(root)**. Нажмите **Save**.
3. Первая сборка занимает 1–3 минуты. Ссылка появится вверху этой страницы:
   `https://<имя>.github.io/passport/`.

Анкета: `https://<имя>.github.io/passport/standard/`.

### Как обновлять потом
Замените файл в репозитории (кнопка карандаш или **Add file → Upload files**). Сайт
пересоберётся сам за 1–2 минуты. Если на телефоне видна старая версия, обновите страницу.

## Этап 2. Отправка писем (Google Apps Script)

1. Войдите в Google-аккаунт студии, от которого будут уходить письма. Откройте
   https://script.google.com и нажмите **Новый проект**.
2. Назовите проект «Паспорт интерьера — отправка».
3. Удалите всё в `Code.gs` и вставьте содержимое файла `apps-script/Code.gs` из репозитория.
   Нажмите 💾 (Сохранить).
4. **Развернуть → Новое развертывание** → шестерёнка → **Веб-приложение**:
   - Описание: `v1`
   - Запуск от имени: **Я**
   - Кто имеет доступ: **Все**
5. **Развернуть**. Google попросит доступ: **Предоставить доступ** → выберите аккаунт.
   На предупреждении «Приложение не проверено» нажмите **Дополнительные настройки** →
   **Перейти на страницу…** → **Разрешить**. Это ваш собственный скрипт, он получает
   только право отправлять письма от вашего имени.
6. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
7. На GitHub откройте `config.js` → карандаш. Вставьте URL в кавычки после
   `appsScriptUrl:` и нажмите **Commit changes**.
8. Проверка: откройте анкету, заполните обложку, нажмите «Отправить», укажите свою почту.
   Письмо с PDF придёт в течение минуты.

### Необязательные настройки скрипта
Script → **Настройки проекта** (шестерёнка) → **Свойства скрипта** → **Добавить**:

| Свойство | По умолчанию | Что значит |
|---|---|---|
| `SENDER_NAME` | Antonovych Design | имя отправителя в письме |
| `DAILY_LIMIT` | 60 | всего писем в сутки |
| `PER_DRAFT_LIMIT` | 3 | отправок с одной анкеты в сутки |
| `MAX_EMAILS` | 3 | адресов в одной отправке |

Если поменяли `Code.gs`: **Развернуть → Управление развертываниями** → карандаш →
Версия: **Новая версия** → **Развернуть**. URL не изменится.
